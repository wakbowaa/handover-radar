# Handover Radar

An outgoing operator fixes the shift state and three to seven critical topics. GenLayer scans the report for actionable coverage. Thin or missing topics return as gaps, and the owner can add a bounded patch before scanning again. Three failed scans escalate the watch.

This is an iterative repair ledger, not a one-shot summary generator. Every scan stores the complete ordered coverage vector.
